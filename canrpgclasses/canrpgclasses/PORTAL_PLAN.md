# Порталы мага

Статус: П1-П3 внесены (не собрано). Осталось П4 и поддержка OpenPortal в редакторе заклинаний.

Базовые умения мага (любая ветка), визуал портирован из candungeons.
- **Врата** - тактический портал в бою: пара точек рядом, живёт секунды.
- **Походный портал** - к ранее поставленному якорю, **выключен по умолчанию**.

## П1. Инфраструктура

### Визуал (клиент)
- `src/Client/Render/PortalPlaneRenderer.cs` - порт `candungeons/src/Client/PortalPlaneRenderer.cs`.
  - Ключ плоскости: `long portalId * 2 + end` вместо `BlockPos`.
  - В `Plane` добавить `TintA`, `TintB` (vec3), в шейдер - uniform'ы вместо зашитого бирюзового.
  - Стадия `AfterBlit`, как в оригинале (сэмплит `primaryFb` и depth).
- `assets/canrpgclasses/shaders/portalplane.vsh|.fsh` - копия в наш домен (чужой домен недоступен).
  - Первый кастомный шейдер в моде: загрузка + перезагрузка на `ReloadShader`, как в candungeons.
- Искры: порт `PortalOpening.Glow` с цветом из пакета, тик 200 мс на клиенте.

### Логика (сервер)
- `src/Core/Portals/PortalManager.cs`, статический, по образцу `ZoneManager` (Start/Stop, тик 250 мс).
  - `PortalPair { Id, OwnerUid, End[2] { Center, AlongX }, Dim, ExpiresMs, Kind }`.
  - Проём 2x3 (как в данжах), ориентация по yaw кастера, округлённая до оси X/Z.
  - Вход: `Contains` по позициям игроков рядом с концом -> `TeleportTo` на другой конец, лицом наружу (`SendViewYaw`).
  - Кулдаун входа на игрока 1.5 с, чтобы не пинговать туда-обратно.
  - Смерть/выход владельца - портал закрывается. На остановке сервера всё очищается, не персистим.
- Общий хелпер `AimGroundPoint` вынести из `ZoneManager` (сейчас private) - нужен Вратам.

### Сеть
- `PortalStatePacket { Id, Open, Kind, End[2], Width, Height, Tint }` в `src/Core/Net/`, в конец `RegisterMessageTypes`.
- Рассылка игрокам в радиусе ~128 от любого конца; раз в 2 с досылка тем, кто подошёл (множество «знающих» на портал).
- Закрытие шлётся всем «знающим».

## П2. Врата (`canrpgclasses:mage_gate`)
- Конец A - 1.5 блока перед магом, конец B - точка прицела (серверный рейкаст, дальность `range`).
- Проверки B: свободный проём 2x3 (`CollisionTester`), прямая видимость от мага, не глубже/выше `maxHeightDiff`.
- Приваты: отказ, если у мага нет доступа к блоку на B (`World.Claims.TryAccess`) - нельзя пробросить себя в чужую базу.
- Пропускает всех игроков (союзники тоже могут отступить). Мобы - нет.
- Цвет по школе ветки не нужен, общий аркан-фиолетовый.
- Баланс в `mage.json`: `"gate": { resource, cooldown: 45, range: 30, duration: 15, maxHeightDiff: 6 }`.

## П3. Походный портал
Два умения:
- **Якорь** (`canrpgclasses:mage_anchor`) - запоминает точку под магом. Один на игрока, в `WatchedAttributes` (dim, x, y, z, yaw). Те же проверки приватов.
- **Портал** (`canrpgclasses:mage_waypoint`) - канал ~10 с, сбивается уроном/движением; открывает пару «здесь <-> якорь» на 30 с.
  - Только то же измерение. Дальний конец не требует загруженного чанка для логики (проверка по позициям игроков), `TeleportTo` грузит сам.
  - Реагент отложен: BalanceConfig хранит только числа, itemcode туда не положить.

Режим назначения, `waypoint.anchorMode`:
- 0 - личный якорь (умение Якорь), каст сразу к нему.
- 1 - только точки админа (`/canrpgportal add|remove|list`, хранятся в сейве, синк клиентам); Якорь скрыт, перед кастом окно выбора (`PortalPickerDialog`), выбор едет в `SpellRequestPacket.Choice` -> `AimContext.Choice`.
- 2 - оба: в окне «Мой якорь» + точки админа.

Снимок места назначения (`PortalShots`): при `/canrpgportal add` и касте Якоря сервер просит клиента снять кадр
(AfterBlit, до HUD), 128x192 RGB + deflate; хранится у точки в сейве / в `Attributes` игрока. Путевой портал
шлёт снимок в `PortalStatePacket.ImageA`, конец A рисует его вместо искажённого фона. Врата без снимка.

Выключатель:
- `mage.json`: `"waypoint": { "enabled": false, cooldown: 1800, channel: 10, duration: 30, maxDistance: 0, reagent: null, reagentQty: 0 }`.
- `enabled: false` -> оба умения (Якорь и Портал) скрыты: фильтр в `SpellAccess.Available`/`CanCast` через новый `Spell.IsEnabled` (дефолт true).

## П4. Полировка
- Звуки открытия/закрытия/прохода (ванильные, без своих ассетов).
- Иконки svg, lang en/ru (`spell-*`, `spelldesc-*`, без длинного тире).
- Сообщения об отказе через `CastFailReason` (нет места, чужой приват, нет якоря, выключено).

## Открытые вопросы
- Пропускать всех игроков или только группу? Системы групп в моде пока нет - по умолчанию все.
- Врата через `ContentSpell` или отдельный C#-класс: портал - новый `ImpactAction.Portal` или прямая логика в спелле? Склоняюсь к `ImpactAction.OpenPortal`, чтобы потом можно было отдать другому классу из редактора.
